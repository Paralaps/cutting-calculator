# Помощник технолога машиностроения

**Версия 1.6** · Сборка (production) калькулятора режимов резания и инженерных справочников для машиностроения.

Приложение считает режимы механической обработки, проверяет их по паспорту станка, подбирает инструмент и материалы и показывает справочные данные — всё в одном интерфейсе, работает в браузере без установки.

---

## Что умеет

### Калькуляторы (4 операции)

| Операция | Что рассчитывается |
|---|---|
| **Фрезерование** | n, Vc, fz/Vf, hm, Pc, Mc, Fc, Q, число проходов, машинное время, стойкость, Ra |
| **Точение** | то же + отрезка и **канавки**: ширина кромки, радиальный ход, число врезаний по ширине и ступеней по глубине, подача по ширине кромки |
| **Сверление** | сверление, рассверливание, зенкерование, развёртывание, растачивание; сила подачи Ff, заходная часть Ltip, полная глубина Lfull |
| **Нарезание резьбы** | **5 способов**: резьбовая фреза, резьбовой резец, метчик/плашка, формующий (бесстружечный) метчик, **накатывание** (ролики/плашка); d₀, диаметр заготовки под накатывание, момент, мощность |

**Общее для всех операций**

- **Рекомендации режимов** по материалу, инструменту и операции с кнопкой **«Подставить»** (Vc, подача, ap, fz, dc).
- **Проверка паспортных ограничений станка**: 24 модели (обороты n_min/n_max, максимальная рабочая подача, мощность, момент) — при превышении выводится предупреждение и рекомендуемая скорость.
- **Технолог-анализ**: прогиб консоли и ожидаемый квалитет, устойчивость (L/D, собственная частота, опасный диапазон оборотов), температура резания и тепловой рост детали, рекомендация СОЖ по материалу и операции, три стратегии по скорости (стойкость / себестоимость / производительность), предупреждения о нефизичных значениях.
- **Классы точности резьбы** ISO 965-1 / ГОСТ 16093-2004: 6H/6G/7H (внутренняя), 6g/6h/6f/6e/8g (наружная) с предельными размерами; для дюймовых резьб — пояснение про ANSI/ASME B1.1.
- **График** мощности, момента и толщины стружки от скорости с безопасной зоной; **печатный отчёт** (класс точности, число проходов, режим обработки); ссылка **«Экономика →»** — открывает отдельную вкладку с уже подставленными данными этой операции.
- **Обмен расчётом**: ссылка на текущий расчёт целиком или файл `.json` (загрузка обратно).
- **Метрическая и имперская** системы: конвертируются и результаты, и поля ввода.
- **История расчётов**, подсказки-схемы параметров (ap, ae, κr, γ, σ), справка, десктопный и мобильный режимы.
- **Навигация** — столбец крупных иконок справа: операции сверху, справочники и «Экономика» ниже; названия показываются подсказкой при наведении, активная вкладка подсвечена.

### Экономика

Отдельная вкладка для расчёта себестоимости и потребности в инструменте. Данные операции (скорость, машинное время, стойкость в деталях на кромку, материал инструмента, удельная сила резания) вводятся вручную или **импортируются одной кнопкой** из текущего расчёта любой операции.

- **Оптимальная скорость** по стойкости и по минимальной себестоимости, себестоимость операции с расшифровкой.
- **Инструментальная сборка**: себестоимость и расход оснастки (патрон, цанга, оправка, корпус и т. д.), выгрузка в CSV.
- **Потребность на период**: сколько режущих кромок и инструментов нужно на месяц, два, три и далее — с расчётом по каждой позиции сборки.


## Стек

React 18 · Vite 6 · TypeScript (strict) · Tailwind CSS v4 · shadcn/ui (Radix) · Vitest · Playwright. Тёмная «индустриальная» тема, янтарный акцент, мобильная версия.

## Качество

- Строгая типизация (`tsc --noEmit`), ESLint без предупреждений.
- **274 юнит-теста** (расчётные формулы, допуски ISO 965 и IT, рекомендации подач и скоростей, инварианты совместимости инструмента, экономика и потребность на период, анализ режима, целостность баз «Аналогов») и **109 e2e-тестов** (Playwright).
- Оценочные значения в справочниках помечены.

## Примечание

Инструмент «Аналоги» создан для технологического подбора взаимозаменяемых марок, сопоставление выполнено по группам ISO, операциям и диапазонам применения и носит справочный характер. Базы инструмента (державки, патроны, корпусной инструмент, сменные пластины) повторяют таблицы каталогов производителей: значения не истолковываются, обозначения и колонки — как напечатаны. Перед применением сверяйте данные с актуальным каталогом производителя.
